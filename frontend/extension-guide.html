Chrome Extension Guide

Pull assignments and materials straight from Google Classroom into StudyMind, without downloading and re-uploading files.

⚠️ You're not using Google Chrome

This extension is built for Chrome (Manifest V3) and only installs and runs correctly in Chrome or another Chromium-based browser (Edge, Brave, Opera). It will not work in Firefox or Safari. If you want to use the extension, open this page in Chrome instead.

1. Install it

  1. Unzip the downloaded file. You should get a folder with manifest.json inside it.
  2. Open chrome://extensions in a new tab.
  3. Turn on Developer mode (top-right toggle).
  4. Click Load unpacked.
  5. Select the unzipped folder.

You should see "StudyMind for Classroom" appear in your extensions list. Pin it to your toolbar for easy access (click the puzzle-piece icon in Chrome's toolbar, then the pin next to StudyMind).

2. Log in

  1. Click the StudyMind icon in your Chrome toolbar.
  2. Enter the same email and password you use on the StudyMind web app.
  3. If you don't have an account yet, create one on the web app first, then come back and log in here.

3. Save a Classroom page

  1. Go to classroom.google.com and open an assignment or posted material.
  2. Click the StudyMind icon, then "Save this Classroom page to StudyMind".
  3. The page's text is pulled in and uploaded as a new document, ready to chat with, quiz on, or summarize back in the web app.

4. Quick chat from the popup

The popup also has a small chat box so you can ask a question about your notes without switching to the web app. It searches all of your uploaded notes, same as the "Ask About My Notes" tool on the Study page.

Troubleshooting

"Could not read content from this page."
The extension only activates on classroom.google.com. If you just installed it, refresh the Classroom tab first, since content scripts only start running on pages loaded after install.

Login says "Invalid email or password" but I'm sure it's right.
Make sure the backend server is actually running (npm start in the backend/ folder). The extension talks to http://localhost:3000, so if that's not running, requests will fail.

Nothing happens when I click the extension icon.
Check chrome://extensions for an error badge on the StudyMind card. If you edited any extension file, click the refresh icon on the card to reload it.

The popup shows the login screen every time.
Your login token may have expired (tokens last 7 days) or Chrome may have cleared extension storage. Just log in again.
